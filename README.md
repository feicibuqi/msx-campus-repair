# 码上修 · 校园扫码报修

> 把报修入口搬到故障现场。扫一下墙上的二维码，校区、楼栋、楼层、点位自动填好，学生只需要拍张照片、写一句话、点提交。

**在线演示**（手机打开，建议从二维码进）：<https://feicibuqi.github.io/msx-campus-repair/>

试试带位置参数的链接，效果就是扫码后看到的样子：

```
https://feicibuqi.github.io/msx-campus-repair/?campus=中心校区&building=知新楼B座&floor=5层&spot=东电梯厅
```

（中文参数也可写成百分号编码，二维码里用的就是编码后的形式。）

## 演示链路

```
楼层里的二维码  →  手机扫码  →  报修页（位置已自动填好）  →  填报修人信息  →  提交
                                                          ↓
                                                    工单号 + 处理进度
```

## 这个项目解决什么

学校其实**有**报修入口，但它在服务大厅深处：打开官网 → 找到服务大厅 → 登录统一身份认证 → 搜索"报修" → 选校区 → 选楼栋 → 选楼层 → 填描述。

**入口离故障现场太远**，于是东西坏了没人报，故障一直拖着。

本方案不改动学校现有后台，只在**入口层**做两件事：

1. **把入口搬到现场** —— 二维码贴在电梯厅、楼梯口、水房门口
2. **把位置交给二维码** —— 校区 / 楼栋 / 楼层 / 点位由链接参数带入，学生不用选

## 页面里可以看的几个点

| 位置 | 说明 |
|---|---|
| 首页位置卡 | **位置零点击自动填好**，并标注"由楼层二维码自动识别" |
| 「对比旧流程」按钮 | 旧流程 8 步 vs 码上修 3 步的对照 |
| 右上角「我的报修」 | 提交后能看到工单状态与时间轴，体现反馈闭环 |
| 提交成功页 | 自动统计"扫码到提交"耗时，并支持复制工单号 |
| 重复报修 | 同一点位 + 同一类型 24 小时内自动合并，不刷屏 |

## 二维码怎么来的

`gen_qrcodes.py` 把位置信息写进链接参数，再批量生成二维码卡片和 A4 打印页：

```bash
python gen_qrcodes.py            # 生成线上地址的二维码（默认）
python gen_qrcodes.py --local    # 生成本机局域网地址的二维码，现场离线演示用
```

产出：

- `qrcodes/单码/` —— 18 个点位各自的二维码图片
- `qrcodes/打印页/` —— 3 页 A4 张贴页，每页 6 张卡片，直接打印
- `qrcodes/汇总预览.png` —— 全部卡片一图看全

中文参数会被转成百分号编码，避免部分扫码器不认 URL 里的非 ASCII 字符。
`verify_qrcodes.py` 可以把生成的二维码**解码回来**做校验。

## 本地运行

```bash
python -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/index.html?campus=中心校区&building=知新楼B座&floor=5层&spot=东电梯厅
```

`index.html` 是**单文件**，没有任何构建步骤和外部依赖，双击也能打开。

### URL 参数

| 参数 | 含义 | 示例 |
|---|---|---|
| `campus` | 校区 | 中心校区 |
| `building` | 楼栋 / 建筑 | 知新楼B座 |
| `floor` | 楼层 | 5层 |
| `spot` | 具体点位 | 东电梯厅 |
| `id` | 点位编号（便于后期统计） | zx-zhixinB-5f-elev |
| `mode` | `live` 隐藏演示辅助按钮；默认 `demo` 显示 | live |

## 文件结构

```
index.html           报修平台本体（单文件，无依赖）
404.html             兜底跳转页（防止扫码器丢参数）
gen_qrcodes.py       二维码批量生成脚本（改 LOCATIONS 即可换点位）
verify_qrcodes.py    二维码解码校验脚本
qrcodes/             生成的二维码与打印页
```

## 说明

- 这是一个**演示原型**，数据存在浏览器本地（localStorage），不会上传到任何服务器。
- 演示时若不想让观众看到"一键填充""模拟推进"这类辅助按钮，用 `?mode=live` 打开。
- 项目背景来自山东大学服务大厅的实测：报修事项未向学生角色开放（返回 403「权限不足」），
  服务大厅内也搜不到面向学生的报修入口。
